## What this is

My data-structures and algorithms practice. Every folder is a problem I got accepted on
LeetCode; the repo is pushed automatically by [LeetHub](https://github.com/QasimWani/LeetHub)
at the moment of acceptance, so the folder list *is* the submission history — nothing is
curated in after the fact.

## How it is organised

One directory per problem, named `<leetcode-id>-<slug>`:

```
0084-largest-rectangle-in-histogram/
├── 0084-largest-rectangle-in-histogram.cpp   # accepted solution
└── README.md                                 # the problem statement
```

The topic index further down (Array, Hash Table, Monotonic Stack, ...) is generated by
LeetHub and rewritten on every push, so a problem is listed under each tag LeetCode
assigns it — the same problem appears in several sections.
